QUICK START
===========

1. Start the vulnerable app:
   $ cd /Users/mariomejia/vuln-web
   $ docker-compose up -d

2. Verify it's running:
   $ curl http://localhost:5000

3. Run the test suite:
   $ bash test-vulnerabilities.sh

4. Scan with nuclei:
   $ nuclei -u http://localhost:5000 -tags xss,sqli,idor -v

5. View results:
   $ cat /tmp/rift-vuln-test-results.txt

WHAT'S INCLUDED
===============

✓ Reflected XSS          - User input echoed without sanitization
✓ Stored XSS             - Comments stored in memory and displayed
✓ Path Traversal         - Read-only access to mock configuration files
✓ SQL Injection          - Vulnerable search endpoint
✓ IDOR                   - Insecure Direct Object Reference on users
✓ Default Credentials    - Weak login (admin/admin123)
✓ Sensitive Data         - API endpoints leak config/secrets
✓ Broken Auth            - Weak password verification
✓ Information Disclosure - Debug endpoints, robots.txt, sitemap.xml

SAFETY GUARANTEES
=================

✗ No RCE                 - Cannot execute system commands
✗ No SSRF                - Cannot make requests to internal services
✗ No Real File Access    - All files are mocked in memory
✗ No Database Access     - In-memory fake database only
✗ No Infrastructure Risk - Completely isolated application

INTEGRATION EXAMPLES
====================

# Test with httpx + nuclei (Rift flow)
httpx -u http://localhost:5000 -sc
nuclei -u http://localhost:5000 -tags xss,sqli,idor -v

# Test with FFUF + nuclei
ffuf -u http://localhost:5000/FUZZ -w wordlist.txt
nuclei -u http://localhost:5000 -tags xss,sqli -v

# Comprehensive nuclei scan
nuclei -u http://localhost:5000 \
  -tags cve,sqli,xss,idor,auth,default-login,exposure,disclosure \
  -severity critical,high \
  -json -o results.json

SUPPORT & TROUBLESHOOTING
==========================

Issue: App won't start
Fix: Check port 5000 is free (lsof -i :5000)

Issue: Nuclei finds no vulnerabilities
Fix: Update nuclei templates (nuclei -update)

Issue: Want to reset the app
Fix: docker-compose restart (clears in-memory data)

Issue: Want to modify vulnerabilities
Fix: Edit app.py and rebuild (docker-compose up -d --build)
